# Freeda 1.0

Create Freeview graphics and printable stereo cards from Full-SBS photographs.

- Parallel, cross-eyed, combined and L–R–L layouts.
- Adjustable crops, frames, rounded corners, colours and captions.
- Web and print sizing, including dpi, bleed and cutting guides.
- JPEG and PNG export, metadata transfer and folder processing.
- Reusable presets, optional saved crops and a German/English interface.

## Installation

Extract the complete package into a writable folder. Start `Freeda.exe` on Windows, `Freeda` on Linux or `Freeda.app` on macOS. Keep the supplied tools and application files together.

Linux requires glibc 2.35 or newer. Linux/macOS metadata transfer requires Perl. The macOS apps are ad-hoc signed and not Apple-notarized. Keep `settings.json` when updating.
