# Freeda 1.1

- Add classic arch shapes and independently adjustable upper and lower image corners.
- Add precise print layouts for Holmes, stereo and Raumbild cards, with dimensions in millimetres.
- Support logos in place of captions, including portable logo presets.
- Expand the colour palette and improve caption spacing and font preview.
- Size web exports by the finished graphic's long edge.
- Simplify crop selection and improve folder processing, progress and cancellation.
- Preserve existing presets from Freeda 1.0.

## Installation

Extract the complete package into a writable folder. Start `Freeda.exe` on Windows, `Freeda` on Linux or `Freeda.app` on macOS. Keep the supplied tools and application files together.

Linux requires glibc 2.35 or newer. Linux/macOS metadata transfer requires Perl. The macOS apps are ad-hoc signed and not Apple-notarized. Keep `settings.json` and your `logos` folder when updating.
